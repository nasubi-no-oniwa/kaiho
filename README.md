# 解放戦力

名前を入れて連打すると、防衛隊スーツの力を何％引き出せるか（解放戦力）がわかる。なすびのお庭の作品です。※非公式のファン診断

- 遊ぶ：https://nasubi-no-oniwa.com/kaiho/
- ゲーム本体は nasubi-site リポジトリの `kaiho/` フォルダにあります（nasubi-no-oniwa.com で公開）
- このリポジトリは記録のルール用：`database.rules.kaiho.json` を上げると自動で otokonoji の `kaiho` の部分だけに反映（鍵は Secrets の `OTOKONOJI_SERVICE_ACCOUNT`。ほかのゲームのルールはそのまま残す）
- 記録するもの
  - `kaiho/n/b0〜b10`：区切りごとの人数（b0＝0%、b1＝1〜9% … b10＝90〜100%）。1ずつしか増やせず、同じ名前は1回しか数えない
  - `kaiho/u/名前のしるし`：その名前がもう数えられたかどうか
  - `kaiho/kc`：識別番号のいちばん新しい番号（101号から1ずつ）
  - `kaiho/k/名前のしるし`：識別怪獣（番号 i・名前 n・フォルティチュード×10 f）。一度決まった番号は変えられない
